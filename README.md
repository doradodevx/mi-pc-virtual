# Mi PC virtual

Sitio web de **Mi PC virtual**, tienda de equipos de cómputo en Tlajomulco de Zúñiga, Jalisco. Caso de estudio académico.

> Mi PC virtual conecta tu mundo

## Contenido

- Inicio con el nombre de la empresa, el globo animado y el audio de bienvenida
- Nosotros: misión, visión, políticas de calidad y objetivo del sitio
- Catálogo de productos y servicios
- Multimedia: video promocional, recorrido por la campaña, audio y galería
- Ubicación con mapa ilustrado de las sucursales
- Preguntas frecuentes
- Contacto con formulario
- Acceso con usuario y contraseña (demostración)

## Ver el sitio

Abre `index.html` en el navegador, o visita la versión publicada en GitHub Pages.

El inicio de sesión y el formulario de contacto son de demostración: no hay servidor, no se envían correos ni se guardan contraseñas.
